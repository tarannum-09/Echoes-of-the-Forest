# Echoes of the Forest

A 3D first-person psychological horror exploration game built using **PyOpenGL** and **Pygame** / **GLUT**.

---

## 📖 Project Overview

*Echoes of the Forest* is a 3D first-person psychological horror game where the player assumes the role of a mother searching for her missing child in a maze-like forest near a remote hill. Rather than relying on traditional combat mechanics, the game emphasizes psychological tension, environmental storytelling, and symbolic gameplay mechanics.

The story explores themes of guilt, denial, and memory. The forest represents unresolved guilt stemming from a brief moment of neglect, while the ghostly entity following you symbolizes self-blame—it advances when ignored and freezes completely when confronted directly.
